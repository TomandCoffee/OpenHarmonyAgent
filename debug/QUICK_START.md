# 📱 手机端调试快速指南

## ⚡ 5 分钟快速开始

### 1️⃣ 手机配置（2 分钟）

```
设置 > 关于手机 > 连续点击"版本号"7 次
设置 > 系统和更新 > 开发人员选项 > 开启"USB 调试"
USB 连接电脑 > 允许 USB 调试
```

### 2️⃣ DevEco Studio（2 分钟）

```
1. 打开 DevEco Studio
2. File > Open > C:\Users\17999\Desktop\创新大赛\OpenHarmonyAgent
3. File > Project Structure > SigningConfigs > Create
4. 顶部工具栏选择设备
```

### 3️⃣ 运行应用（1 分钟）

```
点击 Run 按钮（绿色三角形）
等待应用安装启动
授予必要权限
```

## 🐛 问题记录

### 遇到问题？

1. **设备未识别**
   - 重新插拔 USB 线
   - 检查 USB 调试是否开启
   - 安装华为手机助手

2. **应用安装失败**
   - 检查签名配置
   - 清理设备缓存
   - 重启设备

3. **应用崩溃**
   - 查看 DevEco Studio Log
   - 检查权限是否授予
   - 重新安装应用

### 记录问题

在 [MOBILE_DEBUG_LOG.md](./MOBILE_DEBUG_LOG.md) 中记录：
- 问题描述
- 复现步骤
- 截图
- 设备信息
